# Настройка

Веди человека по шагам. Он не программист: спрашивай по-русски, простыми словами,
по одному вопросу за раз. Не вываливай весь список сразу и не показывай ему
названия полей конфигурации.

## Шаг 1. Техническая часть — всегда первым

Не спрашивай разрешения на проверку, просто выполни:

```
npm run doctor
```

Если чего-то не хватает — пройди установку по порядку из свода правил, раздел
«Установка», и доведи её до конца. Порядок записан там в одном экземпляре, здесь
его не повторяем. **Пароль за человека не вводи и шаг с паролем не обходи.**

Когда всё встало — покажи результат `npm run doctor` человеку одной фразой: всё
готово или чего не хватает.

## Шаг 2. Вопросы

Задавай только то, что нельзя узнать самому. Порядок:

Про площадку — Reels, Shorts, TikTok — **не спрашивай.** Мёртвые зоны кадра в
системе единые и рассчитаны так, чтобы ролик был безопасен на всех трёх сразу.
Спросят сами — ответь, что подгонять ничего не нужно.

1. **Субтитры.** Два вопроса подряд, второй — только если выбран первый вариант:

   — «Субтитры рисуем внутри ролика или их накладывает сторонний сервис?»
   По умолчанию свои: расшифровка речи у системы уже есть, платить и ждать
   ничего не нужно. Третий вариант — без субтитров вовсе, предлагай его сам
   только если человек говорит, что текст на экране ему не нужен.

   — «Кинетические, обычные белые или в цветах вашего стиля?» По умолчанию
   кинетические: фразами, ударное слово крупно. Белые — вариант «как у всех»,
   фирменные берут цвет из дизайн-кода.

   Про размер, положение и подсветку слова не спрашивай: значения по умолчанию
   рабочие, а поменять их можно потом словами.
2. **Озвучка** — есть ли ключ ElevenLabs? Если человек не знает или не хочет,
   спокойно пропусти: система работает с готовыми файлами озвучки, а подключить
   генерацию можно в любой день позже.
3. **Аватар** — нужна ли говорящая голова. По умолчанию нет.
4. **Скрины сайтов** — разрешить ли системе самой открывать сайты и снимать их
   для доказательств. По умолчанию нет, и **при первой настройке прямо
   отговаривай включать.** Скажи так: пока проект не обкатан и первые ролики не
   вышли как надо, лишняя движущаяся часть только мешает искать причину, если
   что-то пойдёт не так. Сначала пусть заработает основное. Вернуться и включить
   можно в любой момент одной фразой — ничего не переделывается и не теряется.

   Заодно скажи, чем это отличается от своих снимков: свои вставляются всегда и
   ни от какой настройки не зависят, а здесь речь про хождение по чужим
   страницам, и ответственность за попавшее в кадр — на владельце.

   Настаивает и хочет включить сейчас — включи без спора, это его право.
5. **Музыка** — класть ли под ролики фон. По умолчанию нет, и это разумное
   значение: голос без музыки звучит чисто, а музыка — вкус, который у каждого
   свой. Спроси одним вопросом и не уговаривай.

   Согласился — скажи, что в системе уже лежат шесть спокойных инструментальных
   треков без слов, и покажи их: `npm run music`. Свои добавляются файлом или
   ссылкой в любой момент, система сама скачает и выровняет громкость. Громкость
   музыки подбирать не проси: она считается от голоса и по умолчанию стоит
   правильно.
6. **Стиль** — есть ли свой дизайн-код. Есть — сразу переходи к подключению
   стиля. Нет —
   оставь нейтральный и скажи, что его можно поменять когда угодно.

Про язык, формат кадра и частоту кадров не спрашивай без нужды: русский, 1080×1920,
30 кадров в секунду — разумно по умолчанию.

## Шаг 3. Ключи

Если человек подключает озвучку или аватар, попроси его вписать ключ в файл `.env`
самому и подтвердить. **Ключи не спрашивай в переписке и не вставляй за него.**

Файл скрытый, сам человек его не найдёт — открой его в текстовом редакторе
(Mac — `open -e .env`, Windows — `notepad .env`) и скажи словами, в какую строку
вставить ключ: сразу после `=`, без пробелов и кавычек, затем сохранить и
написать «готово».

Когда ключ на месте, помоги выбрать голос:

```
node scripts/tts.mjs --voices
node scripts/tts.mjs --demo --text "Короткая фраза для примера"
```

Дай послушать `public/voice-demo.mp3` и подтвердить выбор. Для аватара так же:
`node scripts/avatar.mjs --avatars`.

## Шаг 4. Запись настроек

Правь `config/project.json` по ответам:

- субтитры → `subtitles.mode` и `subtitles.look`;
- музыка → `music.enabled`;
- голос → `voice.elevenlabs.enabled` и `voiceId`;
- аватар → `avatar.provider`, `avatarId`, `placement`;
- скрины сайтов → `shots.web`;
- в конце — `"configured": true`.

Смысл каждого поля описан в `config/schema.md`. Чистку речи не ужесточай без
просьбы: мягкие значения стоят намеренно. **Блок `safe` не трогай:** зоны едины
для всех площадок и меняются только по прямой просьбе владельца.

## Шаг 5. Завершение

Скажи человеку тремя предложениями: что готово, что подключено, и что делать
дальше — прислать озвучку, видео или тему. Про команды не рассказывай: производство
идёт обычными словами.
